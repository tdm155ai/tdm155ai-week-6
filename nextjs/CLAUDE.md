# TDM 155AI week 6: the app

A Next app that renders the Markdown in `content/` (its README is the home page; `content/a/b.md` is `/a/b`) (`lib/content.mjs`). `/activities` (`app/activities/`) shows `content/activities/` as a docs site, the day's plan first in the nav. `/concepts` (`app/concepts/`) shows `content/concepts/` in two levels: the sidebar lists the categories (its folders), then, inside one, only that category's concepts. `/skills` (`app/skills/`) shows `content/skills/` as a docs site: every document in a sidebar, the one you pick beside it, no previous/next pager. The three docs-style routes share `app/components/DocsSidebar.jsx`. `/explorations` (`app/explorations/`, `lib/explorations.mjs`) is a gallery of the cases in `content/explorations/` with a field filter, and a detail page per case that shows its frontmatter images with credits. `/tools` (`app/tools/`) is the Tools tab: cards for `/capture` and `/live` (the other session's webcam capture and gallery, `lib/media.mjs`), `/tools/video` (the generator form, a client component posting to `/api/video`, which spawns `../utils/generate-video.mjs` through `lib/video-jobs.mjs`), and `/tools/videos` (the looping gallery of jobs in `_media/videos/`). The header nav is Activities, Concepts, Skills, Explorations, Tools; the home page is the intro essay (`content/README.md`), and a light `/print` renders any page. Plain JavaScript and the app's own CSS throughout (`app/globals.css`); no TypeScript, Tailwind, or API routes. See the repo `README.md`.

Removed on 2026-10-14, after the copy from The Notebook: the readings section, the student notebook with its `/dictate` and `/transcribe` capture pages, and the `/graphics` package. Nothing in the app needs an API key; keys are only for the scripts in `../utils/`, in the root `.env`.

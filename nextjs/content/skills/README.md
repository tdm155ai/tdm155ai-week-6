# Skills

This week has two kinds of skills: the ones you build in yourself through studies and practice, and the ones you build for Claude. This section is about the second kind. A Claude skill is a folder of instructions, reference notes, and scripts that teaches Claude Code how to do one job well, and it only gets good when the person writing it knows what good looks like.

- [What is a Claude skill?](/skills/intro-to-skills) explains how skills work and how to write one.
- [Origin story](/skills/origin-story) walks through the skill that ships with this repo: it turns your story and photos into a four- or eight-panel comic.

More skills will be added through the week.

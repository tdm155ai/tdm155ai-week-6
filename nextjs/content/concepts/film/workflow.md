The textbook order is pre-production, production, post-production, one after another. The working order overlaps. ScreenSkills describes editors beginning assemblies while shooting continues, so that the cut can reveal a missing shot while the set is still up; Ken Seng's previs breakdowns for *Terminator: Dark Fate* were reviewed by effects departments before anything was filmed; Industrial Light & Magic describes virtual story reels that bring motion-capture shots into an edit while the sequence is still being designed. Each phase produces objects the next one needs, and the phases run as far in parallel as those handoffs allow.

Seeing the workflow as a chain of handoffs makes it something you can study. The storyboard hands the shot list a sequence; the shot list hands the shoot a plan; the shoot hands the edit the footage and the continuity records; the edit hands the shoot a list of pickups. Naming which decision is still open at each handoff makes "pre-production" a precise word instead of a vague one, and shows where a problem found late could have been found early. What goes wrong is the handoff that carries too little: a shot list with no purposes, a take with no log, a rough cut shown without the question it was meant to answer.

A generated pipeline has handoffs too: references to stills, stills to clips, clips to the cut, with consistency checked at each step. Write yours down as a numbered list before you run it. That list is the first draft of a skill, and it is also the fastest way to see which step you do, which a model does, and where you check.

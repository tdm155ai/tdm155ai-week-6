Mix v1 is saved. In v2 you raise the music bed under the narration because the opening felt empty. In v3 you pull it back down because the voice got hard to follow. Each version has a file and a reason. That is iteration in audio, and because nothing in a DAW is destructive (the original take is still there under every effect), it is cheap, which is its danger. You can adjust for three hours and end where you started, a little worse, with no record of the trip.

What turns revising into a study is the same thing that turns fiddling into a [test recording](test-recording.md): a question stated before the change, a saved version on either side of it, a comparison at matched level, and a note on what you heard. More adjustment is not always better. A long session wears down your judgment ([ear fatigue](ear-fatigue.md)), and a sighted comparison pulls you toward the version you just worked on, so the loop can run in circles while feeling like progress. A changed file is not evidence that you learned anything; the log of why you changed it is closer, and the ability to hear the difference next time is the thing itself. That is the distinction between performance in the session and [learning](../learning/learning-vs-performance.md).

With an agent this matters more, not less. A model can iterate on a mix as fast as it can run a plugin and read a meter, and the loop (change, render, measure, change) looks like practice. It is practice for nobody unless the question and the comparison were yours. The same point is made for the agent loop in general, and in film and photography for the cut and the print.
